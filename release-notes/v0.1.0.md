First public test release of Golden Gate Glass: the Liquid Glass of macOS 27 (Golden Gate) on macOS 26.6 Tahoe.

> [!WARNING]
> This release runs unsigned code inside WindowServer and inside your apps. Use it only on a machine you can recover, and keep a backup. If something goes wrong, create `/Users/Shared/GoldenGate/disable` (from Recovery or SSH if needed) and restart.

## Requirements

- macOS 26.6, build **25G72** exactly
- Intel Mac (x86_64)
- System Integrity Protection with Filesystem Protections disabled
- AMFI disabled (`amfi_get_out_of_my_way=1` in `boot-args`)

The installer checks every condition and refuses to install otherwise.

## What's included

- **macOS 27 glass in WindowServer:** every glass surface is rendered with the macOS 27 glass algorithm (refraction, blur, highlights, shadows, light/dark, active/inactive).
- **macOS 27 behavior in apps:** interactive glass buttons, window controls, toolbar button press, scroll edge effect (ThinFilm, Conditional and Hard styles chosen like 27), sidebar (including Catalyst apps such as Podcasts and Books), interactive menus, window corners.
- **Glass transparency slider** in System Settings > Appearance, with the macOS 27 preview; apps, Dock, Control Center, Notification Center and Spotlight follow it.
- **Per-glass recipes:** regular, clear, sidebar, menu, Dock, Control Center, widgets and notifications use their macOS 27 recipes.
- **Golden Gate Glass app:** status, a switch per effect, apps excluded after crashes, logs, turn everything off, uninstall.
- Stays active across restarts and logins without modifying the system volume.

## Install

1. Download `GoldenGateGlass.pkg` below.
2. The package is not signed: right-click it and choose Open, or run `xattr -d com.apple.quarantine GoldenGateGlass.pkg`.
3. Restart after installing.

Later updates install over this version without a restart (reopen apps; WindowServer changes apply at the next restart).

## Known limitations

- The scroll edge effect covers the top edge only, table headers are not yet forced to the Hard style, and its opacity does not follow the transparency slider yet.
- Widgets keep the macOS 26.6 tint matrix; text buttons in notifications are not glass yet.
- The macOS 27 `liquidLens` controls (glass lens on switch, slider and segmented control knobs) are not implemented.
- Surfaces that only exist in macOS 27 (glass alerts and sheets, the Campo background) are not recreated.
